# دستورالعمل سئو فنی و بهینه‌سازی ساختاری (Technical SEO)

این اسکیل الزامات بهبود شاخص‌های فنی سایت، سرعت، کراولابیلیتی (Crawlability) و ایندکس‌پذیری (Indexability) را پوشش می‌دهد.

---

## ۱. فایل Robots.txt و نقشه سایت (Sitemap)
- **مکان نقشه سایت:** بررسی دسترسی به `https://hosseinykala.ir/sitemap_index.xml` یا `https://hosseinykala.ir/wp-sitemap.xml`.
- **دستورالعمل‌های Robots.txt:**
  - اجازه دسترسی به فایل‌های CSS و JS جهت رندر کامل توسط ربات‌های گوگل.
  - مسدودسازی صفحات جستجوی داخلی، صفحات حساب کاربری (`/my-account/`) و سبد خرید (`/cart/`, `/checkout/`).

---

## ۲. شاخص‌های سرعت و Core Web Vitals
- **LCP (Largest Contentful Paint):** بارگذاری تصویر اصلی محصول یا بنر صفحه کمتر از ۲.۵ ثانیه.
- **FID / INP (Interaction to Next Paint):** پاسخ‌دهی سریع عناصر تعاملی.
- **CLS (Cumulative Layout Shift):** تعیین ابعاد دقیق برای تمامی تصاویر و بنرها تا از پرش صفحه جلوگیری شود.

---

## ۳. مدیریت کانونیکال و ریدایرکت‌ها (Canonical & Redirects)
- تمام صفحات باید دارای برچسب `rel="canonical"` به آدرس اصلی با SSL (`https://`) باشند.
- کانونیکالیزیشن آدرس‌های دارای `www` به آدرس بدون `www` (یا برعکس).
- استفاده از ریدایرکت ۳۰۱ برای محصولات ناموجود دائمی به نزدیک‌ترین محصول جایگزین یا صفحه دسته‌بندی مربوطه.
