# دستورالعمل مدیریت محتوا با REST API رسمی وردپرس (WordPress Official REST API)

این اسکیل نحوه تعامل با REST API استاندارد و رسمی وردپرس در سایت `hosseinykala.ir` را بر اساس سطح دسترسی کاربر **ویرایشگر (Editor)** تعیین می‌کند.

---

## 🌐 ۱. مشخصات اتصال و احراز هویت
* **Base URL:** `https://hosseinykala.ir/wp-json/wp/v2`
* **نوع احراز هویت:** HTTP Basic Authentication (با Application Passwords رسمی وردپرس)
* **نام کاربری:** `agent`
* **رمز عبور:** از Application Password تعریف‌شده استفاده می‌شود.
* **نقش کاربر:** **ویرایشگر (Editor)** - دسترسی کامل جهت ایجاد، ویرایش و مدیریت مقالات و محصولات مطابق با استانداردهای رسمی وردپرس.

---

## 📌 ۲. لیست Endpointهای رسمی و مجاز

| متد | آدرس Endpoint | کاربرد |
| :--- | :--- | :--- |
| `GET` | `/wp-json/wp/v2/posts` | دریافت لیست مقالات وبلاگ |
| `GET` | `/wp-json/wp/v2/posts/{id}` | دریافت جزئیات یک مقاله |
| `POST` | `/wp-json/wp/v2/posts` | ایجاد مقاله جدید (به صورت پیش‌نویس `status: "draft"` یا منتشرشده) |
| `POST` | `/wp-json/wp/v2/posts/{id}` | بروزرسانی مقاله موجود |
| `GET` | `/wp-json/wp/v2/product` | دریافت لیست محصولات ووکامرس |
| `GET` | `/wp-json/wp/v2/product/{id}` | دریافت اطلاعات یک محصول |
| `POST` | `/wp-json/wp/v2/product` | ایجاد محصول جدید در ووکامرس |
| `POST` | `/wp-json/wp/v2/product/{id}` | بروزرسانی مستقیم توضیحات، عنوان و مشخصات محصول |
| `GET` | `/wp-json/wp/v2/categories` | دریافت دسته‌بندی‌های نوشته‌ها |
| `GET` | `/wp-json/wp/v2/tags` | دریافت برچسب‌های نوشته‌ها |
| `GET` | `/wp-json/wp/v2/media` | دریافت لیست رسانه‌ها |
| `POST` | `/wp-json/wp/v2/media` | آپلود تصویر یا فایل رسانه جدید |

---

## 🚨 ۳. قوانین و الزامات عملیاتی (Mandatory Rules)

1. **ارسال و بروزرسانی استاندارد:**
   - تمامی درخواست‌ها به صورت JSON استانداردهای رسمی REST API وردپرس ارسال می‌شوند.
2. **رعایت نقش ویرایشگر (Editor):**
   - کاربر دارای دسترسی مستقیم ویرایشگر جهت درج و اصلاح نوشته‌ها و برگه/محصولات در پلتفرم وردپرس است.
3. **حفظ یکپارچگی داده‌های sensitive فروشگاه:**
   - عدم دستکاری بدون هماهنگی در قیمت، موجودی، تنظیمات قالب و اطلاعات حساس.
4. **رعایت کامل استانداردهای سئو و لینک‌سازی داخلی کاننیکال:**
   - استفاده از ساختار HTML استاندارد، درج لینک دسته‌بندی‌ها منحصراً با آدرس کاننیکال `/product-category/{slug}/` (برگرفته از `data/categories.json`) و لینک محصولات با فرمت کاننیکال مستقیم `/product/{slug}/` (برگرفته از `data/id_mappings.json`). استفاده از پارامترهای پرس‌وجو مانند `?product_cat=ID` که منجر به خطای ۴۰۴ می‌شود یا `?p=ID` اکیداً ممنوع است. رعایت لحن انسانی در محتوا.
5. **الزام ارسال فیلد Slug انگلیسی:**
   - در تمام درخواست‌های ایجاد یا ویرایش مقاله/محصول (`POST`), فیلد `slug` باید به صراحت به صورت انگلیسی کوتاه، ساده و مفهومی تنظیم شده و ارسال گردد تا از ایجاد اتوماتیک آدرس‌های فارسی یا بریده‌شده در وردپرس جلوگیری شود.
